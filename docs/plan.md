# 阪急神戸線 作成計画

作成 2026-10-12。2026-10-13 に 9章の 1〜3 と 6（線路・駅・2000系）を走行試作として実施。建物は後日（ユーザー指示）。

ユーザーの指定

- 範囲は大阪梅田〜神戸三宮（32.3km、16駅）。
- 西宮北口で2コースに分ける。コース1は大阪梅田〜西宮北口、コース2は西宮北口〜神戸三宮。
- 標準軌（1435mm）。
- 川を多く渡る。OSM ほか公開資料で位置と形を確かめる。
- 建物は完全再現しない。目印になる建物は必ず置く。家は手続き生成でよい。
- 三宮付近の JR 並走区間は、当面 JR の線路だけ置く（JR の列車は走らせない）。
- ゲームのルールは南海版と同じ。路線とコースを分ける。
- 車両は当面 2000系だけ。
- 南海版のデータとはフォルダを分ける。

## 1. フォルダと流用の方針

- 置き場所は `apps/densha-hankyu/`。南海版 `apps/densha-one-station/` は書き換えない。
- エンジンは南海版から複製する（`src/sim`、`src/game`、`src/render`、`src/audio`、`src/env`、`src/ui`、`src/core`、`src/route` の型と仕組み、`src/world` の部品、`scripts/` の生成・検証）。
- 複製しないもの。南海の路線データ（`src/route/routes/*`）、時刻表、`src/data/osm/*`、`src/data/geometry/*`、`src/data/oncoming-*.json`、南海固有の景観モジュール（なんば、住吉大社、泉大津のタワー、阪堺線、車庫、和歌山市など）、`legacy/`。
- 複製元は南海版の master の特定コミットにする。どのコミットから複製したかを docs に残す。南海版の未コミットの変更は含めない。
- 複製後に南海の名前が残る箇所（放送の行先の既定値、乗り換え案内、駅名標の色、コース一覧）を空にしてから路線データを入れる。

## 3. 川と橋梁

Wikipedia の路線図にある川: 淀川（新淀川）、神崎川、旧猪名川、藻川、武庫川、住吉川、石屋川、都賀川、生田川。駅名の夙川・芦屋川も線路が川を渡る位置にある。

調べること（OSM の waterway と線路の交点で全部出す）

- 川ごとの位置（梅田からの距離）、川幅、橋の形（鋼トラス・鋼桁・コンクリート桁）、上下線が同じ橋か別の橋か。
- 淀川橋梁は3複線のまま渡る。宝塚線・京都線の橋も並べて置く。
- 神崎川橋梁の西に防潮水門がある（Wikipedia）。
- 武庫川橋梁は震災後に旧鉄橋の両側へコンクリート橋を作った（2004年完成）。現在の形を確かめる。
- 夙川・芦屋川は駅が川の上にある。ホームと橋の関係を駅の調査で確かめる。
- 住吉川・石屋川は天井川。線路と川の高さの関係を国土地理院の標高で確かめる。
- 小さな水路（暗渠・用水）は、OSM にあって車窓から見える幅のものだけ置く。

## 4. 駅の配線と構造

railsim-station-research の照合表を全16駅で埋める。照合前に駅の形を決めない。

特に調べる駅

- 大阪梅田。頭端式の大きな駅（10面9線）。神戸線の番線と、宝塚線・京都線のホームの並び。
- 十三。神戸線・宝塚線・京都線のホームが並ぶ。神戸線の番線とホームの形式。
- 塚口。伊丹線の接続。
- 西宮北口。2コースの終点・始発。今津線の接続（今津線は南北で分かれている。平面交差は1984年に撤去）、西宮車庫への入出庫線、待避線の有無。
- 夙川。甲陽線の接続、川の上の駅。
- 神戸三宮。神戸高速線（新開地方面）へ続く通過形の駅。コース2では終点として止める。車止めは置かない（線路は先へ続く）。

## 5. コースと種別

- コース1 `hankyu-kobe-east`（大阪梅田→西宮北口）と逆向き、コース2 `hankyu-kobe-west`（西宮北口→神戸三宮）と逆向き。逆向きは `reverseRoute` で作る。
- 進む向きの名前（下り・上り）は阪急の呼び方を確かめて決める。
- 種別（特急・通勤特急・急行・準急・普通など）と停車駅は、阪急の公式の路線図・時刻表で確かめる。現行ダイヤで神戸線に無い種別は入れない。
- 1コース目で選べる種別を、そのコースの両端に止まるものに限る（南海版と同じ規則）。
- 時間帯（朝・昼・夕・夜）、待避、対向列車は南海版と同じ仕組みで、ダイヤは阪急の公開時刻表から作る。出典の利用条件を確かめてから取得する。
- 放送の文面と乗り換え案内は阪急用に作り直す。

## 6. 車両

- 当面は2000系だけ。阪急の2代目2000系（神戸線・宝塚線用の通勤車）。
- 確かめること。編成両数、車体長、扉数、前面の形、塗装（マルーン、屋根まわりのアイボリー）、行先表示の配置、制御方式（SiC 素子の VVVF と報道あり）、最高速度、加速度・減速度。
- 公式の発表と公開資料で確かめる。分からない値はゲーム用の仮値とし、仮値と書く。
- 対向列車も当面は2000系で出す（車種を増やすのは後日）。

## 7. 景観

- 家・店・マンションは手続き生成（`town-jp.ts`）と OSM の建物の簡略形でよい。
- 目印の建物は個別に置く。候補（車窓から見えるかを OSM と地図で確かめて絞る）。
  - 大阪梅田付近: 阪急梅田駅の駅ビル、HEP FIVE の観覧車、梅田スカイビル、グランフロント大阪。
  - 中津〜十三: 梅田スカイビル、淀川の河川敷。
  - 西宮北口: 阪急西宮ガーデンズ、西宮車庫。
  - 夙川: 夙川公園の松・桜並木。
  - 芦屋川〜六甲: 北側の六甲山系の山並み（遠景）。
  - 王子公園: 王子動物園の観覧車。
  - 神戸三宮: 神戸三宮阪急ビル。
- 山並みは国土地理院の標高で遠景を作る。西へ行くほど線路の北側に山が近づく。
- JR 並走区間。春日野道〜神戸三宮付近で JR の複線を描画だけ置く。並ぶ側と距離は OSM で確かめる。
- 山陽新幹線と交差する（園田〜塚口付近）。新幹線の高架を置く。
- 梅田〜十三は宝塚線・京都線の線路を描画だけ置く。

## 8. 軌間と描画の数値

- 南海版は狭軌の半分 0.535m が複数のファイルに直接書かれている。複製後に `grep -rn "535" src` で全部出し、0.7175m に直す。直したら一か所の定数にまとめる。
- 車両の台車の幅（`train-models.ts`、`emu.ts`）も標準軌に合わせる。
- 線路の中心間隔、建築限界の幅は阪急の値を調べる。分からなければ仮値と書く。

## 10. 確認の方法

- `npm run typecheck`、`verify:routes`、`verify:clearance`、`verify:scenery` を阪急のコースで通す。
- 検査カメラ（`?inspect=1`）で全駅・全橋梁を見る。
- 川の位置は、OSM の川と線路の交点の一覧と、ゲーム内の橋の位置の一覧を並べて比べる。

## 13. 進捗（2026-10-13）

- 複製: 南海版 master の HEAD（bf41ee9 時点）から `git archive` で複製。`legacy/`・`dist/`・`deploy/`・`docs/` は除外。南海のコースのファイルは残し、`src/route/index.ts` に阪急だけ登録。
- 標準軌: `track-mesh.ts` の軌間の半分を 0.7175m、枕木 2.4m、台車の幅（`trains/common.ts`）を広げた。南海の車庫などの専用モジュールの 0.535 は未使用のため未変更。
- 線形: `scripts/route-geometry.ts` に `hankyu-kobe` を追加。OSM の way 名は「阪急電鉄神戸線」。再構成と OSM のずれは最大 41m。最小半径 328m（概形）。
- 川: OSM の waterway と線路の交点を `rivers` に出力（48か所。小水路を含む）。淀川・神崎川・猪名川・旧猪名川・藻川・武庫川を含む橋は全体を橋梁、ほかは名前のある川の前後 25m を橋梁、残りを高架橋（`hankyu-kobe.ts` の `structuresOf`）。
- 高架: OSM の bridge タグの範囲。大阪梅田の駅ビルの下は OSM で tunnel のため、高架橋で手当て。
- 駅の高架・地上とホームの形式: Wikipedia の各駅の記事「駅構造」で照合（2026-10-13）。高架は大阪梅田・中津・園田・王子公園・春日野道・神戸三宮。ほかは地上（神崎川は堤防・盛土上）。大阪梅田（頭端式10面9線、神戸線は7〜9号線）・十三（4面6線）・塚口（2面3線）・神戸三宮（2面3線）は島式・相対式で近似。配線略図との照合は未実施。
- 大阪梅田〜淀川橋梁は全部高架（OSM の途切れを高架橋で埋めた）。
- 御影東の S字 90km/h: 位置不明のため御影の手前 1300〜500m に仮置き。
- 2000系: 形は南海版の通勤形（new）の流用、塗装・3扉・19m だけ阪急。性能は仮値（加速 2.6km/h/s）。
- 時刻表: 駅間距離からの概算（仮値）。
- 自動運転で4コースとも完走（ATS・速度超過なし）を確認。

## 14. 既知の不具合（2026-10-13 ユーザー指摘）→ 修正済み

## 16. 種別・時刻表・沿線（2026-10-13）

- 種別: 普通・特急（大阪梅田・十三・西宮北口・夙川・岡本・神戸三宮）・通勤特急（特急 + 塚口。梅田〜西宮北口だけ）・準特急（特急 + 塚口・六甲。西宮北口〜三宮だけ）。出典は Wikipedia「阪急神戸本線」運行形態と 2025年2月22日改正の報道。急行・快速・準急は停車駅の一覧が確かめられず入れていない。行先は下り 新開地、上り 大阪梅田。
- 時刻表: `npm run timetable:hankyu`（自動運転の最速 +5%、停車 25 秒）。先行の普通は優等列車の 600 秒前に発車（待避が無いため）。
- 沿線: 全線を市街地（`cityZones`）。梅田〜西宮北口は OSM の建物・道路・水面（約2.4万棟）。西宮北口〜三宮は Overpass の混雑（504・502）で未取得、川の水面だけ手作り。
- 目印の建物（HEP FIVE の観覧車、梅田スカイビル、西宮ガーデンズ、王子動物園の観覧車など）の個別の形は未作成（OSM の建物の箱だけ）。
